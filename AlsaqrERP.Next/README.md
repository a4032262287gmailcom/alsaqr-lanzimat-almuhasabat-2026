# الصقر ERP — النواة الجديدة

هذه النواة الأولية تحافظ على نمط الواجهة الحالي: Windows Forms، واجهة عربية RTL، شريط علوي كحلي، قائمة تنقل يمينية، وبطاقات لوحة التحكم.

## التقنية
- C# / Windows Forms
- .NET Framework 4.8
- جاهزة لتوصيل SQL Server بعد مراجعة مخطط قاعدة البيانات الفعلي

## الحالة الحالية
- [x] مشروع مستقل عن مشروع التشغيل القديم
- [x] واجهة رئيسية عربية أولية متجاوبة مع تغيير حجم النافذة
- [x] قائمة أقسام وبطاقات مؤشرات ومناطق تقارير
- [ ] اتصال SQL Server ومخطط البيانات
- [ ] تسجيل الدخول والمستخدمون والصلاحيات الفعلية
- [ ] ربط الشاشات بالأحداث ودوال الأعمال
- [ ] اختبارات البناء والتشغيل والعمليات المحاسبية

**مهم:** لا تعرض الواجهة أرقامًا مالية تجريبية، ولا تنفذ حاليًا عمليات محاسبية. أزرار التنقل مؤقتة حتى يتم ربطها بالوظائف الحقيقية والتحقق من صلاحياتها.
